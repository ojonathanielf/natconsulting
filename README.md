# Nat Consulting Ltd. Website

Professional multi-page website for Nat Consulting Ltd.

## Pages
- `index.html` — Home Page
- `about.html` — About Page  
- `services.html` — Services Page
- `books.html` — Books & Publications Page
- `blog.html` — Blog & Resources Page
- `contact.html` — Contact Page

## How to Deploy on Netlify

1. Create a free account at [github.com](https://github.com)
2. Create a new repository (e.g. `nat-consulting`)
3. Upload all 6 HTML files directly into the repository
4. Go to [netlify.com](https://netlify.com) and sign up free
5. Click **Add new site → Import an existing project → GitHub**
6. Select your repository
7. Leave Build command blank, set Publish directory to `/`
8. Click **Deploy site** — your site will be live in under 60 seconds!

## Activate Contact Form

1. Go to [formspree.io](https://formspree.io) and create a free account
2. Create a new form and copy your form endpoint URL
3. In `contact.html`, find the `<form>` tag and replace the `action` value:
   `action="https://formspree.io/f/YOUR_FORM_ID"`

## Editing Content

Every page is a self-contained HTML file. All CSS and JavaScript are embedded inside each file.

To edit content: open the `.html` file in any text editor (e.g. Notepad, VS Code) and change the text between the HTML tags.
